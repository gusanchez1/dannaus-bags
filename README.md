# 👜 Dannaus Bags — Landing Page & Catálogo Digital

Landing page desenvolvida para a marca **Dannaus Bags**, com foco em identidade visual, experiência do usuário e apresentação de produtos.

🔗 **Acesse:** https://gusanchez1.github.io/dannaus-bags/

---

## 🧠 Sobre o projeto

Este projeto foi criado para simular um cenário real de desenvolvimento front-end para uma marca de moda, transformando a identidade da Dannaus Bags em uma interface digital.

A aplicação apresenta os produtos de forma visual e organizada, com foco em:

- Experiência do usuário (UX)  
- Consistência visual (design system)  
- Navegação fluida  
- Conversão (direcionamento para compra via Instagram)  

---

## 🚀 Funcionalidades atuais

- Landing page completa  
- Catálogo visual de produtos  
- Layout responsivo  
- Navegação com scroll suave  
- Integração com Instagram  
- Identidade visual personalizada  

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica  
- **CSS3** — layout, responsividade e animações  
- **JavaScript** — em fase inicial de implementação  

---

## 🎨 Decisões de design

- Uso de **CSS Variables** para padronização visual  
- Tipografia voltada para identidade de marca  
- Layout com **Grid e Flexbox**  
- Animações leves para melhorar a experiência  

---

## 📱 Responsividade

O layout foi desenvolvido para funcionar bem em diferentes dispositivos:

- Desktop  
- Tablets  
- Smartphones
